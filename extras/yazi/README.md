## Installation

Copy `onehunter.yazi` and/or `onehunter-light.yazi` into `~/.config/yazi/flavors/`.

## Usage

Set One Hunter as your default dark and light flavors in `~/.config/yazi/theme.toml`:

```toml
[flavor]
dark = "onehunter"
light = "onehunter-light"
```

If you only want one variant, set just the matching `dark` or `light` key.
